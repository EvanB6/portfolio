Summer 2026

WEEKLY BLOGS

Week 1

  • First day set up and tour of office.
  • Planned what I would be learning about and filled out internship form for class.
  • Wached youtube videos to get familar with the basics of React language.
  • Downloading Apps like Visual Studio Code and setting up github.
  • Looked at the project code I will be working on to get famialr with it and its set up.
  • Set up localhost of the project so I could run it.

Week 2

  • Finished connecting the localhost app to neon database.
  • Connected to the admin cms pages and admin login.
  • Created a react component that can be edited in the admin cms pages.
  • React component takes user input for name, phone, email, and a message that gets stored in the database and can be read and accessed through the admin cms pages.

Week 3

  • I have began working on a cms page for the web app that the admins can use to make custom forms.
  • It will be a custom form builder that the admins can access to create new forms that can be put on to the website pages that users can be able to input information that will be stored in the online database.

Week 4

  • The basic layout and functions of the form builder are mostly complete.
  • The admin can add questions and set their own questions by typing them up, remove questions, and create the form by saving to the database where it can then be added to the pages through the cms page editor.
  • The question types it currently can handle is true/false and textbox answers where the user inputs text.
  • Next week I will continue to work on the form builder like adding a page in the cms where the admins can view the information submitted from each different form. Also plan to add more editable features to the forms like movable questions and verification so submissions can not be spammed into the database.

Week 5

  • Created the cms pages that show all the forms created then a page that shows a forms submissions printed out in a table.
  • Added to the dashboard the number of forms and submissions tracker.
  • Updated the functions and ui of the form builder, draggable questions to move their position.
  • Created API calls to get the number of submissions.

Week 6

  • Looked at other form builders to see how they build their UI and functionality of their form builders.
  • Edited my UI so it was more striaght forward and user friendly.
  • Working on adding reopening created Forms so that they can be edited.
  • Changed how the data gets saved in the database so its easier to see what questions are being asked and the answer given.
  • Pushed code to the project repo branch for review.

Week 7

  • Edited the code that I pushed to branch after it was reviewed.
  • Changed the layout and format of the form builder. Form builder now starts by showing a list of already created forms and a new form button. The list shows stats of the forms like how many submissions and last updated, along with buttons to edit and three dots with delete function.
  • Added table to reopen and edit already created forms. You can now view, edit, and delete forms.
  • Create, delete, and edit functions work for all forms.

Week 8

  • I combinied all the mutliple pages into one page that links to everything and polished up the UI of the form builder. Instead of a different page for each form.
  • Added a download button that downloads the submissions into a organized txt file.
  • Created a preview screen in the form builder that shows what the form will look like when a user sees it.

Week 9

  • I worked on polishing up the user experience of the form builder.
  • Combined the pages together more so all the information and features are easy to access and you can see all of it on one page.
  • The Form builder starts as a list that you can search through and select what form you want and it expands allowing you to customize it.
  • The submissions for each form are on their page still.

Final Reflection

  • Looking back on my internship I was able to learn and experience alot of new things. I worked on a variety of different aspects that are connected to web development. I was able to use some of the skills that I learned from the DIGIT classes that I have taken. The use of html and css helped me learn the new coding languages that I was using alot faster because it was familar to html. I ended up using TypeScript JSX and React along with tailwind for styling during my time at the internship.

Challenges

  • Some Challenges I faced during the internship was I mainly worked alone and had to solve issues by myself. I was working on an already made project, So I had to look through most of the code and files to figure out how each part functions. A few things I liked about the internship were I would usually meet up with my supervisor and he would look over what I did and give me new ideas of what I could change or add to make it better. Another thing was he would have AI review the code and it make a list of issues and bugs with the code I was making. I thought this was pretty nice because I could see what problems I had and what I needed to fix and I could go back and troubleshoot theses issues.

Reflection

  • Overall, The internship was a great experience that allowed me to work on a product in a real-world setting. It allowed me develop my skills and learn about how the server and client side of the project work together. I got to work with a database called Neon. I got to create APIs that allowed the form builder and submissions to communicate with the database.
